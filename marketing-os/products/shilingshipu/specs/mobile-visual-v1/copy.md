## ③ 标签词汇表

标签一律：黑体 0.8125rem、`--ink-2`、无底色、放行尾右对齐；一行最多一个标签；勾选后不加透明度。标签是一个判断，每个判断都有成立条件——条件不满足就不显示，不用「暂无」顶替。厨房常备品（鸡蛋、葱姜蒜、盐糖油）不挂店铺标签：标签只给会让人跑错店的东西，给鸡蛋挂「普通超市就有」等于没说。

| 标签 | 意思 | 成立条件（数据里必须有） | 不成立时 |
|---|---|---|---|
| 亚超才有 | 普通超市（Safeway / QFC / TJ's）没有，得去 H Mart / 99 Ranch | `stores` 里只有亚超类店 | 不显示 |
| 普通超市就有 | 不必跑亚超 | `stores` 里至少一家非亚超店 | 不显示 |
| 只剩两周 | 本地货这个节气期结束就下市 | 有 `season_end`，且 ≤ 当前节气期末 | 不显示；**没有下市日期不许猜** |
| 刚下来 | 本地货这个节气期开始上架 | 有 `season_start`，且在当前节气期内 | 不显示 |
| 番茄炒蛋 / 蒸排骨（行内小字，不是标签） | 这一样是为哪道菜买的，写菜名；同一道菜带入的几样写同一个名 | 该项是某道菜的主料，由那道菜带入清单；葱姜蒜这类配料不标 | 不显示 |

**删除的标签**：「最便宜 / 眼下最便宜 / 本期最低 / 正便宜」——需要到店价签才能成立，产品没有这项数据。「最后两周」改「只剩两周」并挂在下市日期上。「待核实」不做行内标签，全站只在顶部的开发者提示里出现一次；上线后这一行整条撤掉。

## ④ 什么让它 low（写给创始人）

三个方向都把「low」诊断成了讨好——语气词、药丸标签、圆角卡片、四字空话——并且都治好了。三位评审再看一遍，指出的剩下那一层是同一件事：**页面还在向别人证明自己，而页面上没有人、没有食物。** 具体三条，合成版各自的解法如下。

**1. 页面在对评审说话，不是对读者说话。**
「实拍图位 · 灶台随手拍，45 度」「拿齐了这里会换成盘一盘」「整行可点，落到盘一盘」「分区和顺序照屏幕上的来」——这些句子的听众是合成者和你，不是周三晚上七点的读者。产品一旦向用户描述自己的界面逻辑，就是课设答辩的口吻，比「亲～今日份美味」更根本的廉价。
解法：合成版的版面里没有任何一句这样的话。折叠和复制弹层是真的能点的控件（弹层打开时焦点移进去、Escape 可关、背后不滚）；0% / 100% / 空清单 / 全勾后复制 / 剪贴板失败五个状态都由勾选和按钮真实推导（`list-375-done.png` 等截图是操作出来的，不是画出来的）。「起草 / 待核实」全站只在顶部的开发者提示里出现一次，正文里一个都没有。

**2. 页面上没有一样东西是真的。**
三个方向都用空框或草图顶替照片，再用更多的字去补那个空。可高级感从来不是靠字撑出来的，是靠一件「这个人真的去过」的证据。
解法：合成版没有占位——没有色块、没有图注、没有草图。`<figure class="photo" hidden>` 里放着真图的 `<img>`，图片加载成功才显示，加载不到就不占高度。拍摄要求写在 HTML 注释里给你看，不给读者看。这件事只有你能做：**今晚在灶台上用手机拍一张番茄炒蛋，顶灯，45 度，酱油瓶不用挪，存成 `photo/qiufen-fanqie.jpg`。** 照片进来之后，三个方向加的那些装饰（七十二候、印章、竖排小标、暖纸底）就全部多余，所以合成版一样都没留。同时，作者不只在页脚出现：三行表里的「这道菜不用我教」和宽容声明里的「我再给你挑一样」让读者在页面中段就遇到一个具体的人。

**3. 一种颜色干五份工。**
赭石同时是节气名、标签、链接、按钮底、勾选框、印章、进度条——一个色值承担所有「重点」，看起来就是模板的「主题色」，这是 AI 界面最隐蔽的指纹，纸底和宋体盖不住。
解法：`--accent` 全站只出现在三处：节气名「秋分」、主按钮、勾选框。标签退成 `--ink-2` 黑体，链接用 `--ink` 加下划线，进度线用 `--ink`，「齐了」用 `--ink` 加粗。页面从「套了秋季皮肤的模板」变成「一张印出来的单子」。

**4. 一篇文章，不是一个决定。**（第三位评审补充的）
三版首页都是六七个等重的段落从上到下堆。合成版首屏只允许一个大元素（「番茄」）和一个填色按钮；副标题、三行表、宽容声明、老家这边、折叠、页脚全部在 1rem 及以下，靠细线和留白分层，没有第二个大字、第二个填色。

**剩下的 low 不在字里，在数据里。** 排版和文案能做的到此为止；把「样张 · 未到店核实」这一行划掉，需要你带着手机去一趟 H Mart：番茄现在是不是真在货架上、哪家店、什么价，拍一张。然后在 iPhone 上看一遍——沙箱里是 Noto 字体，真机 PingFang + Songti 下宋体会更瘦、黑体更圆，字距要再收。
